1. Executive Summary & Commercial Value Proposition

UniProcure is a high-security, web-native enterprise procurement management portal tailored to address the rigorous statutory governance, multi-tiered fiscal approvals, and competitive bidding workflows of universities and public academic bodies.

Key Institutional Value Proposition for Decision Makers:
  • Statutory Procurement Integrity: Built specifically to comply with public procurement guidelines (e.g. mandatory 3-quote rule, transparent tender publication periods, sealed competitive quotation evaluations).
  • Fraud & Leakage Prevention: Eliminates manual paper files and informal back-channel approvals by establishing rigid audit trails with immutable officer logs.
  • Objective Bid Evaluation: Built-in Quality & Cost-Based Selection (QCBS) automated comparison matrix scoring technical compliance alongside financial bids.
  • Zero-Backend Presentation Ready: Features an integrated client-side reactive simulation engine (DummyDatabaseService) that permits live, fully interactive demonstrations to evaluation committees and board members with zero server prerequisites.

4. In-Depth Features & Functionalities by Persona

UniProcure isolates capabilities across five authenticated roles plus a public access tier:

1. Institutional Admin Governance

  • User Management: Activate/deactivate faculty accounts, reassign roles, view pending workload count.
  • Vendor Verification Queue: Review statutory TIN, Trade License, and VAT certificates before clearing suppliers.
  • Workflow Hierarchy Engine: Configure monetary approval limits (Tier 1 Dept Head, Tier 2 Dean, Tier 3 Registrar).
  • Governance Rules: Enforce 3 minimum bids, strict budget caps, and auto-escalation timer windows.
  • Executive Analytics: 8-metric KPI suite, spend by category, 6-month trends, top vendor scorecard.

2. Requisition Initiator Department

  • Circular Creation: Author procurement notices with itemized Bill of Quantities (BOQ) and budget limits.
  • Specification Upload: Attach technical drawings, terms of reference (TOR), and procurement rules.
  • Tender Lifecycle Cockpit: Monitor live bidding radar (bid counts, days remaining, submission status).
  • Project History Archive: Complete audit record of fulfilled purchase orders and delivery certificates.

3. Multi-Tiered Approvers Sanctioning

  • Tiered Queue: Dedicated queues for Department Head, Faculty Dean, and Registrar / VC.
  • Side-by-Side Review: Inspect comparative vendor quotations, technical scores, and budget deltas.
  • Formal Decision Cockpit: Approve with digital remarks, reject with mandatory justification, or return for revision.
  • Approval Audit Tracker: Visual chronological stepper displaying officer timestamps and comments.

4. Registered Vendors Contractors

  • Digital Onboarding: Company profile registration with statutory document attachment.
  • Public Tender Explorer: Browse, filter, and review open institutional tender notices.
  • Online Bid Submission: Submit quoted price, delivery timeline, compliance certification, and PDF dossiers.
  • 'My Bids' Tracker: Real-time status indicators (Submitted, Evaluated, Awarded, Disqualified).
  • Work Orders & Invoicing: Milestone delivery reporting and commercial tax invoice uploads.

5. Finance & Treasury Officers (Controllership)

  • Fiscal Budget Monitoring: Real-time monitoring of Annual Budget ($3.5M baseline), Committed Liabilities ($2.18M), and Disbursed Funds ($1.42M).
  • 3-Way Matching Verification: Digital cross-verification between Awarded Work Order, Lab Goods Receipt Note, and Vendor Commercial Invoice.
  • Direct EFT Disbursal Authorization: Settle verified claims, generate Electronic Funds Transfer (EFT) batch references, or return invoices for clarification.
  • Departmental Spend Allocation: Track fund absorption across Science, Engineering, Business, and Arts faculties.

Signature Capability: Automated QCBS Bid Comparison Matrix

UniProcure features an institutional evaluation matrix implementing Quality & Cost-Based Selection (QCBS):

  • Composite Score Calculation: Combines technical evaluation scores (e.g. 70% weight) with commercial quotation competitiveness (e.g. 30% weight).
  • Budget Delta Analysis: Instantly displays quotation variance relative to the approved ceiling (under-budget vs. budget overrun).
  • Automated Award Recommendation: Formulates institutional committee recommendation for immediate executive sanctioning.

5. Production Readiness & Web Security Architecture for Flutter Web

Deploying Flutter Web in enterprise and governmental settings mandates strict client-side hardening and edge infrastructure configurations:

Critical Production Requirements for Web Publishing:
  • Rendering Engine Selection: Build using Flutter's CanvasKit engine (flutter build web --release --no-wasm-dry-run) to guarantee pixel-identical charts, typography, and complex data grids across all browsers.
  • Content Security Policy (CSP): Configure edge servers with strict CSP headers permitting WebAssembly execution ('wasm-unsafe-eval') while blocking unauthorized script origins.
  • Cache Eviction & Service Worker: Utilize the cache-clearing bootstrap in web/index.html to ensure users immediately receive updated bundles upon deployment without manual hard-refreshing.
  • Session Security & Token Shielding: Employ in-memory access token storage backed by HTTP-Only, Secure, SameSite=Strict cookies for token refresh cycles to neutralize XSS token harvesting.
  • Client Route Guards: AuthGuard and PermissionService validate permissions before each route transition, preventing unauthorized direct URL navigation.

Recommended Production Content Security Policy (CSP) Header:

Content-Security-Policy: default-src 'self'; 
  script-src 'self' 'wasm-unsafe-eval' https://fonts.googleapis.com; 
  style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; 
  font-src 'self' https://fonts.gstatic.com; 
  img-src 'self' data: blob: https:; 
  connect-src 'self' https://api.uniprocure.edu; 
  object-src 'none'; frame-ancestors 'none';
